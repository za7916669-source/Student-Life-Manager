# 🎓 Student Life Manager

A console-based task management application built in C++ using Object-Oriented Programming principles to help students organize their daily academic life.

---

## ✨ Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Assign task priorities
- Save tasks using file handling
- Load saved tasks automatically

---

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- STL (Vectors)
- File Handling
- Git
- GitHub
